# tmaptools: tools for thematic maps in R

This package offers a set of handy tool functions for reading and
processing spatial data. The aim of these functions is to supply the
workflow to create thematic maps, e.g. read shape files, set map
projections, append data, calculate areas and distances, and query
OpenStreetMap. The visualization of thematic maps can be done with the
[tmap](https://github.com/r-tmap/tmap) package.

## Installation

`tmaptools` is available on CRAN (version 2.0). The development version
can be installed as follows:

``` r

library(devtools)
install_github("r-tmap/tmaptools")
```

See [installation
procedure](https://github.com/r-tmap/tmap#installation)

## Development

The latest development version can be installed using `devtools`.

``` r

library(devtools)
install_github("r-tmap/tmaptools")
```
